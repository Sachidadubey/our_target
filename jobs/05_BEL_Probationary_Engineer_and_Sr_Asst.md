## 9. Complete Detailed Technical Syllabus (Computer Science & IT)
* **Computer Organization & Architecture:** Machine instructions, addressing modes, ALU, data-path and control unit, instruction pipelining, memory hierarchy (cache, main memory, virtual memory).
* **Data Structures & Algorithms:** Arrays, Stacks, Queues, Linked Lists, Trees, Binary Search Trees, Heaps, Graphs, Sorting algorithms, Divide and conquer, Greedy, Dynamic Programming, Asymptotic notation ($O, \Omega, \Theta$).
* **Operating Systems:** System calls, Processes, Threads, CPU scheduling, Synchronization, Semaphores, Deadlocks, Memory management, Page replacement algorithms, File systems, Disk scheduling.
* **Databases (DBMS):** ER-model, Relational model, Relational algebra, SQL, Normal forms (1NF to BCNF), Transactions, ACID properties, Concurrency control, Serializability.
* **Computer Networks:** Concept of layering (OSI & TCP/IP), Flow and error control, Medium access control, IPv4/IPv6 addressing, Subnetting, Routing (RIP, OSPF, BGP), TCP/UDP, Application layer (DNS, SMTP, HTTP, FTP), Network security basics.
* **Software Engineering & Programming:** Object-Oriented Programming (Java / C++), Software design patterns, SDLC, Testing fundamentals.
